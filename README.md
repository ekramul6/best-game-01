Neon Swarm — a top-down neon arena shooter built for the make.fun best-game-01 bounty. WASD or arrows to fly, mouse to aim, click or Space to shoot. Drifters chase you, spitters shoot back, brutes charge. Grab spread-shot and hull pickups and survive the waves.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
